# КОД.МЭТЧ · unecon.tech · ЛЦТ 2026, спецтрек ФСП

Цифровая платформа обратного подбора IT-специалистов по подтвержденной квалификации. Кандидат проходит практический тест, компания направляет адресное предложение с RUB-вилкой, контакт открывается только после согласия. Основной сценарий работает без опубликованной вакансии и истории ФСП.

## Что открыть первым

1. `presentation/` – презентация PPTX и PDF.
2. `documents/КОД.МЭТЧ_Инструкция_для_жюри.pdf` – действия и ожидаемые результаты проверки.
3. `documents/КОД.МЭТЧ_Техническая_документация.pdf` – архитектура, алгоритмы, валидация, API и запуск.
4. `source/` – читаемые исходники, зафиксированные зависимости, конфигурационные шаблоны, тесты.
5. `evidence/` – датированный отчет проверки, результаты и границы; `MANIFEST.json` / `SHA256SUMS.txt` – контроль состава.

Инструкции доступны также в DOCX/MD. Пароли, токены, SSH-ключи, `.env`, копии production-БД и персональные проверочные аккаунты не входят в комплект. Доступы жюри передаются отдельно через предусмотренный организатором приватный канал; можно создать собственные подтвержденные учетные записи. Репозиторий до отдельного открытия владельцем остается приватным.

## Границы MVP

Реализованы 3 специализации ×2 уровня, объяснимый подбор, контролируемые контакты/PDF, MAX, локальная Qwen, вакансии/отклики и короткие задачи. ФСП работает через демонстрационный adapter до получения боевого API. Индекс подбора – индекс правил, а не вероятность найма. Offline-метрики получены на авторских синтетических данных, ограничения приведены в документации. Проверка обычной web-роли, provider accepted и макет не объявляются фактической приемкой непроверенного native клиента или inbox.
