# КОД.МЭТЧ · unecon.tech · ЛЦТ 2026, специальный трек ФСП

КОД.МЭТЧ – цифровая платформа обратного подбора ИТ-специалистов по подтвержденной квалификации. Кандидат решает практические задания и получает категорию. Работодатель описывает потребность, выбирает подходящих специалистов и направляет предложение с зарплатной вилкой. Контакты открываются по согласию кандидата.

## Как проверить решение

1. Зарегистрируйте кандидата и работодателя на двух адресах электронной почты и подтвердите их по ссылкам из писем.
2. Откройте роли в разных браузерах или профилях браузера.
3. Кандидат заполняет профиль и профессиональную анкету, проходит практический тест и получает подтвержденную категорию.
4. Работодатель создает потребность, получает объяснимый подбор и направляет адресное приглашение.
5. Кандидат принимает предложение; работодатель получает доступ к контактам. Разрешение можно отозвать в настройках кандидата.
6. Подключите MAX в настройках профиля, проверьте команды бота, уведомления и открытие мини-приложения.

Описание решения и пошаговый сценарий: [единая документация с инструкцией для жюри](documents/КОД.МЭТЧ_Документация_и_инструкция.pdf).

## Возможности

- Кабинеты кандидата и работодателя.
- Три специализации: Python Backend, TypeScript Frontend и Data SQL; уровни Junior и Middle.
- Практические задания, серверная оценка, история результатов и сохранение черновика.
- Обратный подбор по навыкам, категории, условиям работы и зарплатной вилке.
- Адресные приглашения, короткий список и управление доступом к контактам.
- Профиль в PDF и импорт сведений из текстового резюме.
- Вакансии, отклики, короткие задачи и уведомления.
- Бот и мини-приложение MAX, письма подтверждения и восстановления доступа.
- Локальная языковая модель Qwen для разбора потребности и пояснения подбора.
- Модуль достижений ФСП с единым форматом данных и адаптером источника.
