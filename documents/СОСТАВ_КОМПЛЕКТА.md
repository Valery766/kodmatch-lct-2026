# Состав комплекта для жюри

| Файл/папка | Формат | Назначение |
|---|---|---|
| README.md | UTF-8 Markdown | Старт, ссылки и карта файлов |
| presentation/ | PPTX + PDF, DOCX/PDF/MD | Финальная презентация по шаблону ФСП/ЛЦТ и текст выступления |
| documents/КОД.МЭТЧ_Инструкция_для_жюри | DOCX + PDF + MD | Пошаговый пользовательский сценарий проверки |
| documents/КОД.МЭТЧ_Техническая_документация | DOCX + PDF + MD | Архитектура, правила, методика, метрики, API и запуск |
| source/ | Исходники | Backend/frontend/worker, lockfiles, тесты и шаблоны конфигурации |
| evidence/ | JSON + MD + JPG | Датированные проверки 11.10, независимая повторная проверка r2 (independent-20261011/, status.json), снимки экрана без секретов, контроль ограничений |
| MANIFEST.json / SHA256SUMS.txt | JSON / TXT | Состав и SHA256 каждого включенного файла |
| FINAL_JURY.zip | ZIP | Итоговый переносимый комплект после проверки распаковки |

Локальный operational handoff, материалы закрытого ТЗ/переписки, credentials и ключи не включаются в отправляемый комплект. Презентация и документы читаются офлайн; работа со стендом и репозиторием требует доступа по указанным ссылкам.
