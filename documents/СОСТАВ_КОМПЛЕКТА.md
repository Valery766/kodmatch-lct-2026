# Состав финального комплекта КОД.МЭТЧ

Команда **unecon.tech** · **11.10.2026**.

| Материал | Форматы | Назначение |
|---|---|---|
| Единая документация и инструкция | PDF, DOCX, Markdown | Описание продукта, архитектуры, алгоритмов, результатов проверки, API и запуска; пошаговый сценарий для жюри |
| Презентация | PDF, PPTX | Представление решения по шаблону ЛЦТ |
| Текст выступления | PDF, DOCX, Markdown | Сопровождение презентации |
| `source/` | Читаемые исходники | Приложение, зависимости, тесты, контрольные наборы и локальный запуск |
| `evidence/` | Markdown, JSON | Результаты проверки алгоритмов и итоговой приемки командой |
| `MANIFEST.json`, `SHA256SUMS.txt` | JSON, текст | Состав файлов и контрольные суммы |

Для оценки откройте [прототип](https://fsp.digital-projects.tech), затем воспользуйтесь [единой документацией и инструкцией](КОД.МЭТЧ_Документация_и_инструкция.pdf). При загрузке в форму конкурса документацию, презентацию, репозиторий и прототип указывайте в соответствующих отдельных полях.
