# КОД.МЭТЧ – материалы для жюри

Команда **unecon.tech** · специальный трек ФСП · ЛЦТ 2026 · финальная редакция **11.10.2026**.

КОД.МЭТЧ соединяет практическое подтверждение навыков и обратный подбор: работодатель описывает задачу и приглашает подходящего специалиста. Кандидат видит условия и самостоятельно разрешает контакт конкретной компании.

## Начните с рабочего сервиса

- [Платформа КОД.МЭТЧ](https://fsp.digital-projects.tech).
- [Бот КОД.МЭТЧ в MAX](https://max.ru/se14505142_1_bot).
- [Исходники на GitHub](https://github.com/Valery766/kodmatch-lct-2026).
- Техническая поддержка: [codematch@mail.ru](mailto:codematch@mail.ru).

Зарегистрируйте две роли на доступных вам адресах, подтвердите email и пройдите маршрут **профиль → тест → категория → подбор → приглашение → решение → контакты**. Для двух ролей используйте разные браузеры или профили браузера.
