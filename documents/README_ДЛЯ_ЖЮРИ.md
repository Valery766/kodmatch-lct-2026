# КОД.МЭТЧ · unecon.tech · ЛЦТ 2026, спецтрек ФСП

Цифровая платформа обратного подбора IT-специалистов по подтвержденной квалификации. Кандидат проходит практический тест, компания направляет адресное предложение с RUB-вилкой, контакт открывается только после согласия. Основной сценарий работает без опубликованной вакансии и истории ФСП.

## Как начать проверку

1. Откройте [сервис](https://fsp.digital-projects.tech).
2. Зарегистрируйте кандидата и работодателя на сайте с подтверждением email (два адреса). Если письмо не пришло – напишите на [codematch@mail.ru](mailto:codematch@mail.ru), команда поможет с доступом.
3. Пройдите шаги [инструкции для жюри](КОД.МЭТЧ_Инструкция_для_жюри.pdf): кандидат → тест → категория, работодатель → потребность → подбор → приглашение, согласие кандидата → контакты.

## Границы MVP

Реализованы 3 специализации × 2 уровня, объяснимый подбор, контролируемые контакты/PDF, MAX, локальная Qwen, вакансии/отклики и короткие задачи. ФСП работает через демонстрационный adapter до получения боевого API. Индекс подбора – индекс правил, а не вероятность найма. Offline-метрики получены на авторских синтетических данных, ограничения приведены в документации. Границы проверки почты и MAX указаны в отчете: прием письма сервером отправки не подтверждает его получение, проверка веб-клиента MAX не подтверждает работу всех телефонных приложений.
