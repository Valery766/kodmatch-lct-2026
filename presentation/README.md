# КОД.МЭТЧ · unecon.tech · презентация ФСП

В комплекте: редактируемая презентация PPTX, её PDF, текст выступления в MD/DOCX/PDF и шрифты Montserrat с открытой лицензией. PDF – экспорт из Microsoft PowerPoint, проверенная версия для просмотра и проектора; PPTX сохраняет редактируемые текст, схемы и диаграмму.

## Соответствие шаблону

| Сдаваемый слайд | Исходный слайд ФСП | Содержание |
|---|---:|---|
| 1 | 7 | Титульный слайд |
| 2 | 8 | Команда, описание и уникальность |
| 3 | 9 | Участники команды |
| 4 | 10 | История, выбор задачи и вызовы |
| 5 | 11 | Техническая и маркетинговая суть |

Методические исходные слайды 1–6 в сдаваемую презентацию не входят. Обязательные исходные 7–11 перенесены первыми пятью: сохранены фоны, мастер, логотипы, исходная палитра и структура смысловых блоков. Поля заполнены материалами проекта. На слайде участников оставлены два реальных участника; пустые карточки 3–5 удалены. На слайдах 2, 3 и 5 сохранены маркеры списков и полужирные подписи шаблона. В карточках участников – роль, публичный адрес и место учёбы; личные телефоны и ники не публикуются. Исходный файл не изменён.

Слайды 6–16 раскрывают решение: сквозной путь, алгоритм подбора, категоризацию, проверку качества, контакты, экраны, MAX, архитектуру, развитие и ссылки. Дополнительные слайды используют палитру ФСП и Montserrat.

## Представление

План выступления – 10 минут. Текст содержит интервалы каждого слайда; точную скорость нужно проверить обычной репетицией. Живой сценарий можно показать после рассказа или вместо части слайда 12. Не показывайте пароли, токены и подписанные параметры запуска MAX.

Для редактирования PPTX используйте Montserrat Regular/Bold из папки fonts, если этих шрифтов нет на устройстве. Шрифты включены в PDF. Экспорт из Microsoft PowerPoint для Mac проверен 11.10.2026: слайды совпадают с PDF, наложений нет; PowerPoint для Windows и проектор не проверялись.
