# КОД.МЭТЧ – клиентская часть

Клиент разработан на React 19.2.8, TypeScript 5.9.3 и Vite 7.3.6. Серверное API определяет роли, результаты тестирования и доступ к контактам. Авторизация использует защищенные сеансовые cookies; секреты подключения хранятся на сервере.

## Запуск

Полный локальный экземпляр: [Docker Compose и Mailpit](../README.md). Для разработки выполните из этой папки `npm ci`, затем `npm run dev`: клиент откроется на `localhost:5173`, API будет перенаправляться на порт `8100`. Команда `npm run build` проверяет TypeScript и создает сборку Vite; [Dockerfile](Dockerfile) размещает статические файлы через nginx.

```bash
node --test tests/navigation-assessment.test.mjs
```

## Пользовательские сценарии

- Главная страница, регистрация с подтверждением почты, вход и выход, восстановление пароля, политика обработки данных и условия использования.
- Кандидат: профиль, предварительный просмотр импорта PDF, анкета, тесты и результаты, история, достижения ФСП, приглашения, вакансии и отклики, практика, уведомления и настройки.
- Работодатель: компания, потребность с подтверждением полей после разбора текста, подбор и пояснения, банк кандидатов, короткий список, приглашения с зарплатой, вакансии и отклики, задания и история.

Маршрут проверяется по роли до открытия формы. Сессия синхронизируется при смене аккаунта и вкладки. `GET /candidate/survey` восстанавливает сохраненную анкету. Черновик теста в `sessionStorage` привязан к пользователю, попытке и серверному сроку; после завершения он очищается. Баллы и срок прохождения определяет сервер.

Зарплатная вилка отображается в рублях за месяц до вычета НДФЛ. Контакты доступны только компании, которой кандидат дал разрешение; одинаковое правило действует для API и PDF.

## MAX

Мини-приложение открывается через `/mini/max` с официальным SDK MAX. Сервер проверяет подпись `initData`, срок действия и привязку аккаунта. Коды привязки одноразовые. Команда подтвердила работу бота, привязки, уведомлений и открытия приложения на реальных аккаунтах.

## Дизайн и удобство

Используются официальные цвета, шрифты и материалы ФСП из `public/`. Прозрачный знак КОД.МЭТЧ – самостоятельный знак продукта. Интерфейс адаптирован к мобильному экрану; доступны видимые индикаторы фокуса, подписи полей, переход к основному содержимому, управление модальными окнами с клавиатуры и режим уменьшенного движения. Закрытое мобильное меню исключается из взаимодействия. Поддержан режим системных контрастных цветов.

Импорт резюме требует подтверждения владельца. Самоописание показывается отдельно от квалификации, подтвержденной тестом. Индекс подбора отражает совпадение навыков и условий. Тестовые достижения ФСП выделены как демонстрационные записи.
