# КОД.МЭТЧ – frontend

React19.2.8, TypeScript5.9.3, Vite7.3.6. Клиент использует cookie API; секреты и пароли в bundle отсутствуют. [Backend API](../backend/API_CONTRACT.md) определяет результаты тестов, роли и раскрытие контактов.

## Запуск

Для полного локального прототипа используйте [Compose + Mailpit](../README.md). Для разработки из этой папки `npm ci`, затем `npm run dev` – localhost5173, proxy API8100. `npm run build` выполняет TypeScript и production Vite-сборку; [Dockerfile](Dockerfile) создаёт статический web с nginx.

```bash
node --test tests/navigation-assessment.test.mjs
```

## Поведение

- Главная, регистрация/подтверждение email, вход/выход, восстановление, privacy/terms.
- Кандидат: профиль, PDF import-preview с явным подтверждением, анкета/тест/результаты, история, ФСП-мок, приглашения, вакансии/отклики, практика, уведомления и настройки.
- Работодатель: компания, потребность с подтверждаемым structured parse, подбор/пояснения, отдельный банк, shortlist, приглашения с зарплатой, вакансии/отклики, короткие задания и история.
- Неверный ролевой маршрут разрешается до mount формы. Сессия синхронизируется при смене аккаунта/вкладки. GET `/candidate/survey` восстанавливает сохранённую анкету. Черновик теста в sessionStorage ограничен конкретным user/attempt/server expiry и очищается после завершения; локальное хранение не продлевает deadline и не меняет оценку.
- Обязательный диапазон зарплаты подписан в рублях за месяц до вычета НДФЛ. Контакты доступны только по разрешению конкретной компании; решение контролирует сервер, в том числе PDF.

## MAX

Единственный активный мессенджер – MAX: `/mini/max`, официальный bridge SDK и проверка исходного signed initData сервером. Обычная вкладка без подписанного запуска не доказывает native launch. Legacy Telegram endpoint не используется и возвращает404; старые совместимые поля внутри моделей не означают активную UI-интеграцию. MAX/HMAC секреты берутся только из private environment.

Реальный MAX signed launch/привязка/собственные уведомления и live LLM ранее проверены отдельно; свежие датированные доказательства собираются в [evidence](../../../evidence/). Unit-тесты не заменяют настоящий мессенджер, внешний inbox или физическое устройство. Полный independent WCAG/native iOS/Android аудит не заявлен.

## Визуальная система и проверки

Официальные FSP palette/assets/fonts/notices находятся в public/ и используются без изменения оригинальных байтов. Прозрачный знак КОД.МЭТЧ является отдельным product mark. Реализованы focus-visible, labels, skip link, modal focus trap/Escape/return focus, закрытая mobile-nav inert, reduced-motion и forced-colors. Снимки прежних QA-проходов не являются запускной зависимостью и не входят в чистый source. [Манифест происхождения](../../source-manifest.json) доказывает byte-exact source/runtime bridge.

PDF-import не устанавливает квалификацию. Self-report отдельно от подтверждённых тестовых данных. Балл подбора не является вероятностью найма; ФСП-мок не выдаётся за боевую верификацию. Локальный test Mailpit не отправляет настоящие письма внешним пользователям.
