# КОД.МЭТЧ – исходный код

КОД.МЭТЧ – платформа обратного найма ИТ-специалистов команды unecon.tech для специального трека ФСП, ЛЦТ 2026. Кандидаты подтверждают квалификацию практическими заданиями, работодатели получают объяснимый подбор и направляют предложения с зарплатной вилкой. Контакты открываются конкретной компании по решению кандидата.

Действующий прототип: https://fsp.digital-projects.tech. Единственный мессенджер проекта – MAX. Команда проверила работу пользовательских сценариев, бота и получения писем на реальных подтвержденных аккаунтах.

## Состав и запуск

Исходники серверного приложения, клиентские файлы и Dockerfile соответствуют развернутому релизу `20261011T104017Z` (версия 0.1.0). В комплект входят инструкции запуска, закрепленные версии зависимостей, автоматические проверки и два набора данных для воспроизводимой оценки подбора. Секреты подключения задаются отдельно через защищенные переменные окружения.

Локальный экземпляр использует собственную базу и тестовую почту Mailpit. На публичном сайте регистрация подтверждается письмом; уведомления и мини-приложение доступны в MAX. Подтвержденные категории и права на контакты определяет сервер. Локальная языковая модель предлагает структуру потребности работодателя и порядок объяснений, составленных из проверенных фактов.
